# 🛵 RentRide
Platform digital penyewaan motor dan mobil — booking instan, transparan, terpercaya.

## 📌 Deskripsi
RentRide menghubungkan penyewa kendaraan dengan mitra rental secara online 
melalui verifikasi identitas, pembayaran digital, GPS tracking, dan asuransi 
terintegrasi.
